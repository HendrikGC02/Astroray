# Reference corpus v2 -- design (pkg284 Phase 1)

Supersedes `reference-corpus-design-2026-09.md` for the parity population. Charter, gate form,
band rule and re-bless rule: `benchmarks/reference_corpus/README.md` ("Corpus v2"). Bands: `gates_v2.toml`
(Cycles 5.2.0 LTS CPU, seed 278, 64 spp gate / 1024 spp reference, MC seeds 278-280).

Assets: every scene is generated by code (`build_corpus.py`); the only external files are the v1 synthetic
VDBs (CC0, `assets/volumes_*.vdb`). No third-party assets. Gate (c) roles (owner 2026-09-29):
`v2_light_tree`, `v2_textures_opvm`, `v2_camera_geometry`.
