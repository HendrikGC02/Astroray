The full spectral-rendering milestone landed on main and shipped in a new Blender addon: the light-intensity Power slider (pkg213), sodium / atomic-line emission refixed with physically-correct energy-normalized SPDs — no mercury regression (pkg214), and CPU+GPU byte-mirrored luminance-weighted hero-wavelength importance sampling (pkg206), which a Cycles-parity review then caught was biased on the default GPU band — fixed with a windowed-CDF renormalization before it could ship. In parallel the project-index database was rebuilt to be genuinely useful (owns/whatis/script/body-search/auto-rebuild, pkg215) and wired into the agents so they actually use it (pkg216). Live Blender-MCP debugging then surfaced and fixed two real bugs: native shader nodes rendering grey on Blender's Material Output (#635) and a CPU tree-light-sampler that rendered spot/point/sun scenes fully black (#637). Parked: GPU refractive / dispersive caustics — a glass prism still casts a black shadow instead of a caustic; filed as pkg217 and deprioritized by the owner.
