Shader nodes + GPU caustics: both headline issues closed

Architect-led session — 6 PRs merged; shader-node constant-folding fixed end-to-end and the GPU black-shadow caustic bug root-caused to a one-switch addon fix.

2026-08-23 · architect-led multi-package run · generated by run-report

This session attacked the owner's two top pressing issues and closed both. Shader-node compatibility — the addon's constant-folding that silently greyed out any Color Ramp / Mix / Math / Mapping downstream of a texture — is now fixed end-to-end by a three-part per-texel op-VM (pkg219a mapping + coordinates, pkg219b VM core, pkg219c opcode fill-out), all CPU+GPU and register-neutral. GPU caustics — glass casting a black shadow instead of a caustic — turned out not to need the large new SMS kernel the plan called for: reading the code first revealed the pkg113 photon-caustic pipeline was already wired and tested, just never switched on from the addon (pkg217, a ~2-line fix). Also shipped: the GPU lamp emission red-shift fix (#638) and a project-index gh-sync bug (0 → 579 issues/PRs indexed). Nothing failed. The SMS-based wavefront caustic remains deliberately parked as a possible future quality upgrade — the black-shadow bug it was meant to fix is already closed.
