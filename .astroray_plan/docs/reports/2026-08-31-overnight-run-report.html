Flagship · pkg131

Zero-knob adaptive sampling

Replace the samples = N knob with a physically-grounded stopping rule: per-pixel noise is estimated against a scalar-luminance half-buffer (Dammertz 2010, as Cycles implements it), the threshold is auto-derived from the sample budget, and a pixel retires once its brightness-relative noise falls below it. Easy regions stop early; hard regions keep sampling. No user knobs.

Convergence — why it can stop early

RMSE of a smooth 2-D integral vs sample count, measured from the shipped sampler. The progressive (hash-Owen Sobol′, pkg224) sequence converges faster than white noise's 1/√N — so a truncated per-pixel count is still well-distributed. That prefix property is what makes early stopping safe.

Architecture note. The GPU wavefront is a flat persistent-thread work pool (pixel = w % numPixels), the deliberate launch-amortizing design behind the perf ceiling. Adaptive is layered on it as a compacted active-pixel round — the regen kernel indexes a compacted active list, per-pixel sample counts drive a per-pixel divide, and convergence + 3×3 mask dilation + compaction run host-side reusing the tested core. It is byte-identical when off and opt-in via the progressive sampler. Not a wave-based rewrite.

What did not merge

pkg225-S1 — hair ray-curve intersection. The implementation is well-researched (pbrt-v3 Curve::Intersect, cite-verified; Catmull-Rom↔Bézier cross-checked against Cycles) with a real closed-form analytic test. Per the "no half-assing the hair flagship" directive it was not forced green; the bug was localized to the depth-0 hit test and recorded on the WIP branch as a precise next-session starting point. Verifying turned an unknown into a known, actionable defect.
