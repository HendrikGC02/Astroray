## Goal

**Before:** Astroray has no validated line-emissivity data; the previous spec's
`j_ν(ρ, T, U, λ)` 4D grid stored *line-integrated* emissivities with ambiguous
units, solid-angle normalisation, and wavelength reference.

**After:** A small, committed, schema-validated table of line-integrated
emissivities for eight optical lines, generated by a Python preprocessing
script, with an explicit physical data contract (quantity, units, normalisation,
wavelength reference, abundance/ionising assumptions, grid, interpolation).

**First measurable deliverable:** a line-ratio figure from the generated table
showing **Hα/Hβ = 2.86 ± 2 %** at `Tₑ = 10⁴ K`, `nₑ = 100 cm⁻³` (the pinned
Storey & Hummer 1995 Case-B value), with the same ratio tracking the tabulated
temperature dependence of the Case-B decrement.

---

## Context

HII-region emission is line-dominated: discrete atoms and ions at physically
fixed wavelengths. First-principles emissivities need full photoionisation
equilibrium — far too expensive at render time, so a committed table is the right
trade. This package produces it; pkg46 consumes it in the existing volume
transport (`GridMedium` + pkg270 emission), the first prerequisite of the nebula
track. Without an unambiguous data contract the loader cannot tell an integrated
line from a per-wavelength density, and the rendered Balmer decrement is untestable.

### Key design decisions

#### Data contract

**Quantity — integrated line, not per-λ.** Each entry is a *line-integrated*
emissivity: power emitted per unit volume in one line, integrated over its
profile, `j_line = ∫ j_ν dν` [erg s⁻¹ cm⁻³]. It is not a spectral density;
never divide it by a wavelength width. For recombination lines

    j_line = n_e · n_p · α_eff(line, T_e) · h·ν           [erg s⁻¹ cm⁻³]

**Emissivity and solid-angle convention.** Emission is isotropic. The stored
quantity is the line emissivity **per steradian**, `j` [erg s⁻¹ cm⁻³ sr⁻¹ per
line], defined by `I_line = j · L` for an optically thin slab. It is `j_line / (4π)`,
not the 4π-integrated `j_line` (a 4π-integrated quantity would be named `4π j`).
The sidecar records `solid_angle_convention: "per_steradian"` (unit-tested). The
renderer's volumetric emission is radiance per unit length per steradian (see
`include/astroray/volume/volume_emission.h`); pkg46 must not multiply by 4π again.

**Lines versus continuum.** The eight discrete line entries are line-integrated
emissivities: units `erg s⁻¹ cm⁻³ sr⁻¹` **per line** (one value per line, not a
density in λ). A per-wavelength continuum (free-free, bound-free, two-photon) is
a different quantity, units `erg s⁻¹ cm⁻³ sr⁻¹ nm⁻¹`; it lives in a separate
array (Phase 1: not tabulated) and must never be mixed into the line array.

**Wavelength reference.** Wavelengths are **air-referenced**, matching
Osterbrock & Ferland, CLOUDY line labels, and the CIE 1931 2° observer (#837)
that defines the engine range. Vacuum conversion is documented for cross-code
comparison, not applied in the renderer:

    λ_vac = λ_air · n_air(λ_air)
    n_air − 1 = 2.735182e-4 + 131.4182/λ_air² + 2.76249e8/λ_air⁴
        (λ_air in Å; Edlén 1966)

**Line list (8 discrete entries, air nm).** All lie inside
`[kLambdaMin, kLambdaMax] = [360, 830]` nm:

| Line | λ_air (nm) | Transition |
|---|---|---|
| Hα | 656.28 | H I Balmer-α |
| Hβ | 486.13 | H I Balmer-β |
| [OIII] | 495.9 | O III ¹D₂ → ³P₁ |
| [OIII] | 500.7 | O III ¹D₂ → ³P₂ |
| [NII] | 654.8 | N II ¹D₂ → ³P₁ |
| [NII] | 658.3 | N II ¹D₂ → ³P₂ |
| [SII] | 671.6 | S II ²D₃/₂ → ⁴S₃/₂ |
| [SII] | 673.1 | S II ²D₅/₂ → ⁴S₃/₂ |

The λ axis is these discrete centres, not a uniform spectral grid; a future continuum table would use the full 360–830 nm engine axis.

**Grid axes and ranges.**

| Axis | Symbol | Range | Points | Spacing |
|---|---|---|---|---|
| Electron density | n_e | 10¹ – 10⁶ cm⁻³ | 20 | log-uniform |
| Electron temperature | T_e | 5000 – 20000 K | 16 | linear |
| Ionisation parameter | log U | −4 – 0 | 16 | linear |
| Line | λ | 8 centres above | 8 | discrete |

**Regime, abundance, and absolute normalisation (pinned per grid point).**
Regime is **Case B** (Lyman optically thick, Balmer thin) — valid only there.
Normalisation inputs are pinned so absolute emissivity is reproducible: solar
`He/H = 0.085` (Asplund et al. 2009, ARA&A 47, 481) `(frozen 2026-09-22, lead
may adjust)` giving `n_p/n_e = 0.855` for fully ionised H+He `(frozen 2026-09-22,
lead may adjust)`. The sidecar stores `n_p/n_e` and, for every grid point
`(n_e, T_e, U)`, each emitting-ion fraction `x_ion = n(ion)/n(element)`
(O²⁺/O, N⁺/N, S⁺/S) from the Kewley & Dopita 2002 Table 3 ionisation-balance
polynomial there, normalised so `Σ_ion x_ion = 1`. The ionising SED is pinned to
a **blackbody `T_eff = 4×10⁴ K`** `(frozen 2026-09-22, lead may adjust)`, with
`U = Q(H)/(4π r² n_H c)`; model, `T_eff`, and normalisation are recorded per grid
point. `j_line` uses only these stored `n_e`, `n_p`, `x_ion`, never a default or
neighbour value. Phase 2 records the actual CLOUDY SED and abundance, labelled
as such.

**Interpolation and out-of-range.** Trilinear in transformed coordinates
`(T_e, x=log₁₀ n_e, y=log₁₀ U)`: values interpolate **linearly**, axes are
log-transformed (never log-interpolate `j`). In the cell with lower corner
`(T_i, x_j, y_k)` and offsets `t,u,v ∈ [0,1)`, `j = Σ_{c∈{0,1}³} w_c·j_c`,
`w_c = (t or 1−t)(u or 1−u)(v or 1−v)`. Requests outside the declared
`(T_e, n_e, U)` ranges **raise** (tested), never extrapolate or clamp; metadata
records the valid ranges. `tests/test_cloudy_tables.py` must carry ≥3 independently
calculated off-grid golden cases (half a grid step off the nodes, one per axis)
whose expected values come from the analytic Storey & Hummer 1995 `α_eff` fit,
not the table, agreeing within 5 %.

**Fixed ratios.** [OIII] 500.7/495.9 = 2.98 and [NII] 658.3/654.8 = 3.0 are
fixed by branching ratios; hard-code them, do not fit.

#### Discrete-line spectral injection

The engine evaluates per-wavelength densities at sampled wavelengths
(`EmissionSpectrum::eval`, `SampledWavelengths`), so a δ line point-sampled is
missed with probability 1. Lines use a **normalized bin deposit**: each line is
`j_λ = j_line·δ(λ − λ_line)`; pkg46 places the whole `j_line` in the half-open
cell of the engine 1 nm emission grid (360–830 nm, 471 samples —
`kDeviceEmissionLambdaMin/Step/Samples`, `emission_spectrum.h`) containing
`λ_line` and stores `j_cell = j_line / 1 nm`, so `∫ j_λ dλ = j_cell·1 nm = j_line`
exactly (two centres in one cell sum; lines are never point-sampled or resampled).
`tests/test_cloudy_tables.py` deposits all 8 lines and asserts
`Σ_cells j_cell·Δλ = Σ_lines j_line` to 10⁻⁵ relative, every `λ_line ∈
[kLambdaMin, kLambdaMax]`.

#### Phase 1 — published-table fallback (default)

Hydrogen recombination lines from the **pinned** Storey & Hummer 1995 (MNRAS 272,
41) Case-B `α_eff` tables; the exact table version and row(s) used are recorded in
the sidecar metadata. Metal (forbidden) lines from CHIANTI v10 / Osterbrock &
Ferland collision strengths as a fallback. No CLOUDY required; this is the
first-science-deliverable path.

#### Phase 2 — optional pyCloudy/CLOUDY driver

CLOUDY / pyCloudy **generates the metal lines** (and may regenerate hydrogen),
driven offline via pyCloudy to the same schema. Used only when CLOUDY is
installed, and must reproduce the Phase 1 schema and line ratios within the
stated tolerances before replacing the fallback output.

#### Storage format

Header: magic `AHII`, uint32 version, 4 × uint32 dimensions, float32 axis
ranges, padded to 64 bytes. Data: float32 row-major `[n_e][T_e][logU][line]`.
Line wavelengths and all contract fields live in the JSON sidecar, never in the
binary. Rows are line-integrated; their renderer-facing form is the normalized
bin deposit above. Total ≈ 640 KB (committed).

## Acceptance criteria

- [ ] `scripts/generate_cloudy_tables.py --fallback` runs with no CLOUDY and writes `data/emissivity/hii_emissivity.bin` and `data/emissivity/hii_emissivity_metadata.json`.
- [ ] **First measurable deliverable:** Hα/Hβ at `Tₑ = 10⁴ K`, `nₑ = 100 cm⁻³` is 2.86 ± 2 % against the pinned Storey & Hummer 1995 Case-B value (metadata records the table version/row).
- [ ] Hα/Hβ tracks the tabulated temperature dependence (≈3.04 at 5000 K, ≈2.75 at 20000 K) within 5 %.
- [ ] Table shape is `(20, 16, 16, 8)`; all values finite and non-negative.
- [ ] [OIII] 500.7/495.9 within 5 % of 2.98; [NII] 658.3/654.8 within 5 % of 3.0.
- [ ] Schema/units test: metadata declares `erg s⁻¹ cm⁻³ sr⁻¹` per line, `solid_angle_convention: "per_steradian"`, air-referenced wavelengths, and the grid ranges; the binary header matches.
- [ ] Out-of-range `(T_e, n_e, U)` requests raise; a test asserts this.
- [ ] Off-grid interpolation golden cases (≥3, each half a grid step off the nodes, one per axis, expected values independently calculated from the S&H `α_eff` fit) pass within 5 %.
- [ ] Discrete-line energy conservation: depositing the 8 lines on the engine 1 nm grid preserves `Σ_cells j_cell·Δλ = Σ_lines j_line` to 10⁻⁵ relative; every λ_line is inside `[kLambdaMin, kLambdaMax]`.
- [ ] The line table contains no per-wavelength continuum entries.
- [ ] Binary < 1 MB; `tests/test_cloudy_tables.py` passes.
- [ ] `scripts/cloudy_table_format.md` documents quantity, units, normalisation inputs, interpolation, and the discrete-line spectral-injection contract well enough to write the loader from it alone.

## Non-goals

- Do not write the C++/plugin loader. That is pkg46.
- Do not tabulate per-wavelength continuum, dust emission, or absorption.
- Do not model radio recombination lines (optical only here).
- Do not model planetary nebulae (different density/temperature regime).
- Do not require CLOUDY as a build or test dependency.
