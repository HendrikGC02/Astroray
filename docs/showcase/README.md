# pkg74 example artefacts

These PNGs are committed as representative examples of what
`benchmarks/showcase/runner.py --quick` produces. They are *not*
regenerated by CI — they are static documentation. The live artefacts
land in `benchmarks/showcase/output/` (gitignored).

## Phase 2 (this round)

- [`example_integrator_compare.png`](example_integrator_compare.png) —
  the new `integrator_compare` scene: the same Cornell-with-glass
  rendered through every safe entry from
  `astroray.integrator_registry_names()`. Driven by the registry, so
  newly added integrators appear automatically; failed integrators
  show as labelled FAIL tiles instead of silently disappearing.

- [`example_integrator_timing.png`](example_integrator_timing.png) —
  horizontal bar chart of total render time per integrator on the
  same scene + SPP. The bar chart is sorted ascending so a glance at
  the top tells you the cheapest integrator.

- [`example_convergence_curve.png`](example_convergence_curve.png) —
  log-log RMSE vs SPP for the Cornell box, against the highest-SPP
  in-run render (256 spp) as the reference. Phase 2 added the legend
  annotation showing the **fitted log-log slope**; a correct
  unbiased Monte-Carlo path tracer should approach −0.5 (RMSE
  ∝ 1/√spp). On the implementer machine Astroray's path tracer
  measures **−0.453** here.

## Categories surfaced in `stats_summary.csv` (Phase 2)

Every row in `stats_summary.csv` carries columns grouped by category:

| Prefix | Category | Examples |
|---|---|---|
| (no prefix) | Phase 1 originals | `mean_luminance`, `p99_luminance`, `firefly_count_4x_mean`, `render_seconds`, `peak_rss_mb` |
| `geom_` | Geometry | `geom_triangles`, `geom_spheres`, `geom_materials`, `geom_lights` |
| `mem_` | Memory | `mem_peak_rss_mb`, `mem_image_mb`, `mem_gpu_used_mb` |
| `time_` | Timing | `time_scene_build_ms`, `time_render_ms`, `time_total_ms` |
| `samp_` | Sampling | `samp_pixels`, `samp_per_pixel`, `samp_total_paths` |
| `qual_` | Quality | `qual_p50_luminance`, `qual_dynamic_range`, `qual_variance_mean`, `qual_convergence_rate_slope` |
| `spec_` | Spectral | `spec_wavelength_min_nm`, `spec_hero_band_histogram` |
| `gpu_` | GPU | `gpu_available`, `gpu_device_name`, `gpu_optix_available`, `gpu_used` |
| `intstat_` | Integrator-specific | `intstat_caustic_connections`, `intstat_sms_attempts`, `intstat_buffered_training` |

The HTML index renders each category as a collapsible `<details>`
section so the wide CSV stays scannable. Columns whose values would
require a future C++ binding (e.g. `geom_bvh_nodes`,
`mem_gpu_used_mb`, `samp_camera_rays`) are present but emit empty
cells until the binding lands — the framework is forward-compatible.

See `.astroray_plan/packages/pkg74-engine-benchmark-showcase.md` for
the spec and `.astroray_plan/docs/engine-benchmark-research.md` for
the §2 stats catalog.
