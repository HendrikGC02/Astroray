# pkg74 example artefacts

These two PNGs are committed as representative examples of what
`benchmarks/showcase/runner.py --quick` produces. They are *not*
regenerated by CI — they are static documentation. The live
artefacts land in `benchmarks/showcase/output/` (gitignored).

- [`example_material_zoo.png`](example_material_zoo.png) — the
  registry-driven material zoo at 96×96 / 32 spp. Each tile is one
  registered material rendered as a sphere under uniform sun + grey
  background. Thirteen materials shown; emitter and wrapper types
  are skipped per `benchmarks/showcase/config.py:ZOO_SKIPLIST`.

- [`example_convergence_curve.png`](example_convergence_curve.png) —
  log-log RMSE vs SPP for the Cornell box, against the highest-SPP
  in-run render (256 spp) as the reference. The 256-spp self-vs-self
  point is intentionally excluded from the plot (RMSE = 0 compresses
  the log axis to garbage); it is still recorded in `stats_summary.csv`.

See `.astroray_plan/packages/pkg74-engine-benchmark-showcase.md` for
the spec and `.astroray_plan/docs/engine-benchmark-research.md` for
the references.
